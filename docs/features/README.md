# 기능 페이지

기능 하나가 어떻게 동작하는지 이 폴더의 페이지 하나로 읽는다. 흐름·규칙·실패 응답·테스트 위치가 한곳에 있다.

| 항목 | 내용 |
|---|---|
| 파일 이름 | `NN-기능이름.md` (스토리맵 순서) |
| 양식 | [`_양식.md`](_양식.md) |
| 시나리오·정책 정의 | 기능 페이지로 옮긴 UC·P 정의는 여기가 정본이다 |
| 규칙 정의 | R-ID 정의는 도메인 모델 문서에 둔다. 여기는 한 줄 요약만 둔다 |
| 이력 | 이력 표와 [밑그림](../records/sketches/)이 서로 링크한다(docs-check가 확인) |
