# sketch

이슈 하나의 의도·접근·결과를 남기는 이력 문서다. 정본이 아니다.

| 항목 | 내용 |
|---|---|
| 파일 이름 | `<이슈번호>-<slug>.md` (slug는 브랜치 이름의 요약과 같게) |
| 양식 | [`_양식.md`](_양식.md) |
| 연결 | 머리말의 `features`에는 동작·규칙·정책·API를 바꾼 기능 페이지만 적고, 그 페이지의 이력 표가 이 sketch를 링크한다(docs-check가 확인). 문서만 고친 작업은 `features: [없음]`이다 |
| 커밋 | 이슈 시작 때 만들고 PR에 함께 커밋한다 |
| 상태 | 작업 중에는 `status: 진행 중`이고, PR을 올리기 전에 `결과`를 채우고 `완료`로 바꾼다. 병합된 sketch는 모두 `완료`다 |
