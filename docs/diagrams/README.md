# 다이어그램

문서에 들어가는 그림의 원본(`.d2`)과 생성물(`.svg`)을 한곳에 둔다. 기능 페이지의 흐름도와 다른 문서의 그림이 모두 여기 있다. ERD의 그림만 아직 Mermaid로 ERD 문서 안에 있다.

| 항목 | 내용 |
| --- | --- |
| 원본 | `.d2` 텍스트. 사람이 고치는 것은 이 파일뿐이다 |
| 생성물 | `.svg`. `d2 <이름>.d2 <이름>.svg`로 만들어 커밋한다. 직접 고치지 않는다 |
| 파일 이름 | 기능 페이지의 흐름도는 페이지 이름과 같게(`03-참여하기`). 다른 문서의 그림은 `<문서>-<그림 이름>` |
| 배치 | 흐름은 격자(`grid-rows`와 `grid-columns` 둘 다 지정)로 두고, 상자는 쉬운 말에 응답 코드를 둘째 줄로 붙인다 |
| 한계 | SVG는 임시 글꼴로 만들었고, `.d2`를 고친 뒤 SVG를 다시 만들었는지는 CI가 확인하지 않는다(글꼴 고정과 CI 비교는 #114에서 미뤘다). `.d2`를 고치면 같은 커밋에서 SVG도 다시 만든다 |
