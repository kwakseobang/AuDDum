# 다이어그램

문서에 들어가는 그림의 원본(`.d2`)과 생성물(`.svg`)을 한곳에 둔다. 기능 페이지의 흐름도가 지금 여기 있고, Mermaid를 D2로 바꾸는 작업이 끝나면 다른 문서의 그림도 모인다.

| 항목 | 내용 |
| --- | --- |
| 원본 | `.d2` 텍스트. 사람이 고치는 것은 이 파일뿐이다 |
| 생성물 | `.svg`. `d2 <이름>.d2 <이름>.svg`로 만들어 커밋한다. 직접 고치지 않는다 |
| 파일 이름 | 기능 페이지의 흐름도는 페이지 이름과 같게(`03-참여하기`). 다른 문서의 그림은 `<문서>-<그림 이름>` |
| 배치 | 흐름은 격자(`grid-rows`와 `grid-columns` 둘 다 지정)로 두고, 상자는 쉬운 말에 응답 코드를 둘째 줄로 붙인다 |
| 한계 | SVG는 임시 글꼴로 만들었다. 글꼴과 CI의 d2 설치·최신 여부 비교는 3단계에서 정한다 |
