# 오류 코드

서버가 JSON으로 돌려주는 오류 코드 20개를 도메인별로 모았다. 응답의 `code`는 이 표의 코드이고, 상태는 HTTP 응답 코드다. 4로 시작하면 요청이 잘못되었거나 지금은 받을 수 없다는 뜻이고, 5로 시작하면 서버 문제다. 메시지는 사용자에게 그대로 보여 줘도 되는 문장이다. 로그 수준은 서버가 이 오류를 기록하는 중요도다.

## 공통

| 코드 | 상태 | 메시지 | 로그 수준 |
| --- | --- | --- | --- |
| `MALFORMED_REQUEST` | 400 | 요청 형식이 올바르지 않습니다. | INFO |
| `VALIDATION_FAILED` | 400 | 요청 값이 올바르지 않습니다. | INFO |
| `UNAUTHENTICATED` | 401 | 로그인이 필요합니다. | WARN |
| `FORBIDDEN` | 403 | 권한이 없습니다. | WARN |
| `INTERNAL_ERROR` | 500 | 서버 내부 오류가 발생했습니다. | ERROR |

## 회원

| 코드 | 상태 | 메시지 | 로그 수준 |
| --- | --- | --- | --- |
| `MEMBER_SUSPENDED` | 403 | 정지된 회원은 이 요청을 할 수 없습니다. | INFO |
| `MEMBER_NOT_FOUND` | 404 | 존재하지 않는 회원입니다. | INFO |
| `MEMBER_NOT_ACTIVE` | 409 | 정상 상태의 회원이 아닙니다. | INFO |

## 투표

| 코드 | 상태 | 메시지 | 로그 수준 |
| --- | --- | --- | --- |
| `INVALID_OPTION` | 400 | 존재하지 않거나 이 투표에 속하지 않는 선택지입니다. | INFO |
| `POLL_NOT_DELETABLE` | 403 | 관리자가 숨긴 투표는 삭제할 수 없습니다. | INFO |
| `POLL_NOT_FOUND` | 404 | 존재하지 않는 투표입니다. | INFO |
| `DUPLICATE_POLL` | 409 | 직전에 만든 투표와 같은 질문입니다. | INFO |
| `POLL_CLOSED` | 409 | 마감된 투표입니다. | INFO |
| `POLL_NOT_HIDDEN` | 409 | 숨김 상태의 투표가 아닙니다. | INFO |
| `POLL_NOT_PUBLIC` | 409 | 공개 상태의 투표가 아닙니다. | INFO |
| `POLL_RATE_LIMITED` | 429 | 투표를 너무 자주 만들 수 없습니다. 잠시 후 다시 시도해 주세요. | INFO |
